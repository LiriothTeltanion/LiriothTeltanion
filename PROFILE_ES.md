## Proyectos principales

### 🎧 Nova Music Lab

**Nova Music Lab 1.6.0**, desplegada el **2026-11-12**, es una aplicación React 19/TypeScript local-first que presenta el archivo musical público de Kevin / Lirioth y permite que cada visitante convierta exportaciones compatibles de su propio historial en un museo privado dentro del navegador. El Living Artist Atlas puede recorrerse por escuchas o de la A a la Z, con biografías legibles, retratos, relaciones, géneros y procedencia transparente. El snapshot público contiene **82.661 reproducciones**, **20.908 canciones** y **6.593 entradas de nombres de artista** —no una afirmación de 6.593 personas únicas—; el **94,2 %** de las reproducciones tiene una familia analítica y 457 entradas cuentan con evidencia detallada separada de la clasificación automática.

- [Demo pública](https://liriothteltanion.github.io/NovaMusicLab/)
- [Código fuente](https://github.com/LiriothTeltanion/NovaMusicLab)
- Pages sirve el commit `edf90379a3f0` y la etiqueta del producto apunta a `e0d49d294034`. En la [ejecución del despliegue](https://github.com/LiriothTeltanion/NovaMusicLab/actions/runs/43221653133) pasaron los recorridos de navegador, los controles de privacidad y tamaño del paquete, y la prueba de Pages.

### א Ivrit Sheli

**Ivrit Sheli 2.13.0** es un producto full-stack trilingüe para aprender hebreo desde situaciones reales. Cada palabra se enseña con una escena pintada y animada: 157 de las 165 escenas que admiten fondo pintado ya lo tienen, con versión de noche para el tema oscuro, y una misma familia de personas aparece en las 240. Conserva un modo local privado con SQLite y añade React 19/TypeScript, FastAPI, PostgreSQL 17, Alembic, Docker y una experiencia autenticada con límites explícitos. Su base verificada suma **434 pruebas de backend + 1096 de frontend = 1530 pruebas automatizadas**. La interfaz funciona en inglés, español y hebreo con RTL; el recorrido público usa datos sintéticos y mantiene desactivadas por defecto las llamadas pagadas a proveedores.

- [Abrir el demo público](https://ivrit-sheli.onrender.com)
- [Código fuente y guía de ejecución](https://github.com/LiriothTeltanion/IvritSheli)
- El demo corre en **Render**, plan `render-free`, región Frankfurt, como **staging de un piloto privado, no como producción**. Redesplegado a mano el 2 nov 2026 con la 2.13.0 (commit `9d64fc7`) y comprobado de nuevo el 3 nov 2026: versión y commit correctos, PostgreSQL preparado, diccionario de 240 entradas, CSP estricta y HSTS. Un inicio de sesión con Google se completó a mano en este despliegue. El plan gratuito duerme, así que la primera carga puede tardar minutos.
- **2.13.0 es la versión publicada**: el código, la etiqueta Git y el GitHub Release coinciden en v2.13.0. Una sesión live exitosa con GitHub OAuth y el reingreso después del logout siguen pendientes de verificación E2E.
- El GIF y las capturas son las **revisadas de la 2.13.0** que publica el propio proyecto, tomadas el 2 nov 2026 en el commit `1ff60b9ec910` con un aprendiz local genérico, sin nombre ni progreso personal. Pasaron revisión de privacidad, de hashes y de identidad de bytes antes de publicarse. La matriz completa de navegador y la verificación de proveedores siguen siendo puertas aparte. No contienen historial privado, tokens ni registros de producción. El despliegue histórico de **Railway está apagado**.

### 💙 NovaFit

NovaFit 4.2 es una aplicación local de escritorio y terminal con Python, Tkinter y SQLite. Incluye cuatro espacios de analítica —Command Center, Trend Lab, Consistency Map y Training Atlas—, 124 pruebas automatizadas, perfiles aislados, interfaz EN/ES/HE con RTL en hebreo, doce temas, Sport & Data Coach, reportes portátiles, migración segura, distribución para Windows y una vitrina PWA instalable en GitHub Pages. La web usa exclusivamente datos demostrativos y no lee ni publica el historial personal del escritorio.
